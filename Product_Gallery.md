## How to Add Your Media

### Adding Images:
1. Upload your images to `media/images/` folder
2. Use this format in markdown:
   ```markdown
   ![Alt text]("C:\Users\Rashid\Downloads\download (3).jpeg" "Optional title")
   ```

### Adding Videos:
1. Upload your videos to `media/videos/` folder
2. Create thumbnails in `media/thumbnails/` folder
3. Use this format in markdown:
   ```markdown
   [![Thumbnail text](./media/thumbnails/thumb.jpg)](./media/videos/video.mp4)
   ```

### Supported Formats:
- **Images:** .jpg, .jpeg, .png, .webp, .svg, .gif
- **Videos:** .mp4, .webm, .mov, .ogv
